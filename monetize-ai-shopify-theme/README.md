# Monetize with AI Shopify Theme

This is a fresh Shopify theme-style project prepared for the **Five-Day AI Monetization Launch**.

## What is inside?

- `layout/theme.liquid` is the main page wrapper.
- `sections/announcement-bar.liquid` adds the launch bonus message.
- `sections/hero.liquid` adds the homepage hero.
- `sections/launch-bundle.liquid` adds the launch bundle section under the hero.
- `templates/cart.liquid` adds cart reassurance copy.
- `snippets/mobile-sticky-cta.liquid` adds the mobile sticky CTA.
- `assets/theme.css` controls the bold, startup-style design.
